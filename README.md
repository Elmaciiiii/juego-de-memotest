# 🧠 OpenDislex - Lector Accesible para Personas con Dislexia

> Proyecto desarrollado con el objetivo de mejorar la accesibilidad web para personas con dislexia, facilitando la lectura mediante herramientas visuales y auditivas personalizables.

---

## 🏅 Objetivo del Proyecto

OpenDislex busca ofrecer una solucion accesible y adaptable para personas con dislexia. A traves de un lector con personalizacion de estilo, lectura por voz y modo oscuro, se pretende reducir la carga cognitiva y mejorar la experiencia de lectura en la web.

---

## 🧑‍🤝‍🧑 Publico Objetivo

Este proyecto esta dirigido a:

- Personas con dislexia
- Docentes y profesionales que trabajan con personas con dificultades de aprendizaje
- Usuarios que requieren una interfaz de lectura mas amigable
- Personas que buscan mejorar la accesibilidad web

---

## 💡 Funcionalidades

### ✅ Funcionalidades actuales

- 🔊 **Lector de texto**: Lee palabra por palabra en voz alta el contenido del sitio web.
- 🎨 **Personalizacion de estilo**: Cambia fuente, tamano, color de fondo y texto.
- 🌙 **Modo oscuro**: Mejora la lectura en entornos con poca luz.
- ⏯️ **Controles de reproduccion**: Iniciar, pausar y detener la lectura en cualquier momento.
- 📏 **Carga de contenido desde URL**: Se puede ingresar un enlace para extraer y leer el texto.
- 📱 **Diseno responsivo mejorado**: Adaptado para dispositivos moviles con menu lateral optimizado.

### 🧪 Funcionalidades futuras (en desarrollo)

- 📂 **Conversion de documentos (PDF, DOCX)**  
  Permitir subir archivos y aplicarles formato accesible.

- 💾 **Guardar preferencias de estilo**  
  Almacenar las configuraciones del usuario para futuras visitas.

- 🌐 **Soporte multilingue**  
  Incluir traducciones para llegar a mas usuarios en diferentes idiomas.

- 🕘 **Historial de lectura**  
  Registro de los enlaces o textos leidos previamente.

## 🔧 Mejoras Recientes

### Mejoras de Responsividad

- **Menu lateral mejorado**: Se ha anadido un boton de cierre (cruz) en la esquina superior derecha del menu lateral para facilitar su uso en dispositivos moviles.
- **Overlay optimizado**: El overlay que aparece al abrir el menu lateral ahora se ajusta correctamente al ancho del menu.
- **Organizacion de botones**: Los botones "Pegar Enlace" y "Cargar Contenido" ahora se muestran horizontalmente en pantallas grandes y verticalmente en dispositivos moviles.

### Optimizacion de Codigo

- **Eliminacion de duplicaciones**: Se ha limpiado el codigo CSS y JavaScript para eliminar estilos y funciones duplicadas.
- **Organizacion de media queries**: Las media queries se han consolidado para mejorar la legibilidad y mantenimiento.
- **Mejoras de accesibilidad**: Se han mejorado los estilos para garantizar una mejor experiencia en todos los dispositivos.
